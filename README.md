# delCppl

After EffectsのAEPファイルに蓄積したCPPlの内容を削除するWindows用コマンドラインツールです。CPPlの容器は保持します。

## ウィンドウ版 delCpplUI

`delCpplUI.exe`を起動し、「ファイルを選択…」ボタンからAEPを選ぶか、ウィンドウへドラッグ＆ドロップしてください。ファイルサイズとCPPlの内容サイズなどを表示します。

カード形式の画面に、ファイルサイズ・CPPlの内容・割合をまとめて表示します。ライト／ダークに対応し、初期状態はWindowsのアプリテーマに自動追従します。右上の「テーマ」ボタンで、自動→ダーク→ライトの順に切り替えられます。選択したテーマはアプリを終了すると自動に戻ります。ファイル選択・保存のダイアログはWindowsの設定に従います。

「実行して保存…」を押すと保存ダイアログが開きます。既定の保存名は`名前_patched.aep`です。保存先を指定するとCPPlの内容を削除し、検証後に保存します。原本は保持し、入力ファイルと同じ保存先は指定できません。別の既存ファイルへの保存には、保存ダイアログで上書き確認が表示されます。

対象はAEPファイル1つです。複数ドロップ時は最初の1つだけを扱い、フォルダやサブディレクトリの検索は行いません。CPPlがない・空・削除非対応の構造の場合、「実行…」は無効になります。解析・保存中は「中断」ボタンで中断できます。保存ダイアログのキャンセルではファイルを作成しません。

## 使い方

```powershell
delCppl "D:\work\project.aep"
delCppl "D:\work\project.aep" -patch
delCppl "D:\work" -p -sub
delCppl "D:\work\scene?.aep" -p
delCppl "D:\work\project.aep" -p -overwrite
```

ファイル・フォルダを複数指定できます。パスに空白がある場合やワイルドカードを指定する場合は引用符で囲んでください。

| オプション | 内容 |
|---|---|
| `-info` | パス、ファイルサイズ、CPPlの個数・内容サイズ・位置などを表示。操作指定がない場合の既定動作 |
| `-patch` / `-p` / `-f` | CPPlの内容を削除し、結果を保存 |
| `-sub` | サブディレクトリも検索 |
| `-overwrite` | 原本をリネームして保持し、元の名前で処理結果を保存。`-patch`などの指定が必要 |
| `-wait` | 終了時に何かキーを押すまで待機。エラーやヘルプ表示時も有効 |
| `-help` / `--help` / `-h` | ヘルプ表示 |

`-info`と`-patch`は併用できます。引数なしの場合はヘルプを表示します。`--`以降はオプションとして解釈しません。

ショートカットの「リンク先」を`"C:\tools\delCppl.exe" -p -wait`にすると、AEPやフォルダをドラッグして処理したあと、結果を確認してからキー入力で閉じられます。Ctrl+Cによる中断後や標準入力がリダイレクトされている場合は待機しません。

フォルダでは`*.aep`を検索します。拡張子の大文字小文字は問いません。ワイルドカードはファイル名部分の`*`と`?`に対応します。リンクやジャンクションは対象外です。

## 保存と中断

通常は同じフォルダへ`名前_patched.aep`を保存します。既存ファイルがあれば`名前_patched_1.aep`などの連番を使います。

`-overwrite`では原本を`名前_original_YYYYMMDD_HHMMSS_連番.aep`にリネームして保持します。日付・時刻は実行PCのローカル時刻です。原本退避後の保存に失敗した場合は元の名前への復元を試み、復元できない場合は退避先を表示します。

フォルダ・ワイルドカード検索では、上記の出力・原本退避名に一致するファイルを除外します。これらを処理する場合はファイルを直接指定してください。対象一覧は処理開始前に確定し、同じパスの重複は除きます。

CPPlがない・空の場合は変更せず、出力も作りません。不正な構造や非対応の構造は書き換えず、ほかのファイルの処理を続けます。

Ctrl+CまたはCtrl+Breakで中断できます。未完成の一時ファイルを削除し、確定済みの出力は保持します。原本退避から保存・復元までの短い区間は中断を遅延します。強制終了・電源断では一時ファイルやリネーム済み原本が残ることがあります。

| 終了コード | 内容 |
|---|---|
| `0` | 正常終了（変更不要を含む） |
| `1` | 対象なし、読込・保存失敗、非対応形式などの失敗あり |
| `2` | 引数不正 |
| `130` | 中断 |

## 対応範囲

Windows x64向けです。RIFX / Egg!形式のAEPを対象とし、削除はトップレベルにCPPlが1つある場合に対応します。複数・入れ子のCPPlは情報表示のみ対応します。AEPXには対応しません。

出力は構造と対象外データの一致を検証します。ただし、このリリースでは実際のAfter Effectsによる再読込・レンダー検証は未実施です。処理後は使用するAEでコンポジション、素材参照、エフェクト、出力設定などを確認してください。
