# delCppl / delCpplUI

After EffectsのAEPファイルに蓄積したCPPlの内容を削除する、Windows x64用ツールです。

| アプリ | 操作方法 | 対象 | 保存方法 |
|---|---|---|---|
| **delCpplUI.exe（GUI版）** | ウィンドウのボタン・ドラッグ＆ドロップ | AEPファイル1つ | 保存ダイアログで指定 |
| **delCppl.exe（コンソール版）** | コマンド・ショートカットへのドラッグ＆ドロップ | ファイル、複数ファイル、フォルダ、ワイルドカード | 別名保存、または原本を退避して上書き |

両方とも`.aep`が対象です。`.aepx`には対応していません。CPPlの入れ物を残し、その内容を削除します。

## GUI版：delCpplUI.exe

### 基本操作

1. `delCpplUI.exe`を起動します。
2. **「ファイルを選択…」**からAEPを選ぶか、ウィンドウへAEPをドラッグ＆ドロップします。
3. ファイルサイズ、CPPlの内容サイズ・割合などを確認します。
4. **「実行して保存…」**を押します。
5. 保存ダイアログで保存先とファイル名を指定します。

### 保存先と原本

既定の保存名は`名前_patched.aep`です。保存先や名前はダイアログで変更できます。

入力した原本はそのまま残します。原本と同じファイルへの保存はできません。別の既存ファイルを保存先に選ぶと、上書き確認が表示されます。

保存ダイアログをキャンセルした場合、ファイルは作成しません。

### 対象・中断・テーマ

- **1ファイル専用です。** 複数ファイルをドロップしても、最初の1つだけを読み込みます。フォルダやサブディレクトリの検索は行いません。
- CPPlがない・空・削除に対応していない構造の場合、保存ボタンは無効になります。
- 解析・保存中は**「中断」**ボタンで中断できます。
- 右上の**「テーマ」**ボタンで、自動→ダーク→ライトの順に切り替えられます。自動はWindowsのアプリテーマに従います。再起動時は自動に戻ります。

## コンソール版：delCppl.exe

以下は、PowerShellで`delCppl.exe`のあるフォルダを開いて実行する例です。

### 情報を表示する

対象のパスだけを指定すると、CPPlの情報を表示します。**この段階ではファイルを変更しません。**

```powershell
.\delCppl.exe "D:\work\project.aep"
```

`-info`を明示しても同じ動作です。引数を何も指定せずに起動すると、ヘルプを表示します。

### CPPlの内容を削除して保存する

`-p`を付けると、CPPlの内容を削除して保存します。

```powershell
.\delCppl.exe "D:\work\project.aep" -p
```

| 処理したい対象 | コマンド例 |
|---|---|
| 複数のファイル | `.\delCppl.exe "D:\work\a.aep" "D:\work\b.aep" -p` |
| フォルダ直下のAEP | `.\delCppl.exe "D:\work" -p` |
| サブフォルダを含むAEP | `.\delCppl.exe "D:\work" -p -sub` |
| 名前が一致するAEP | `.\delCppl.exe "D:\work\scene*.aep" -p` |

パスは引用符で囲んでください。フォルダ指定では`*.aep`を検索します。ワイルドカードは**ファイル名部分の`*`と`?`**に対応します。拡張子の大文字小文字は問いません。リンク・ジャンクションは対象外です。

### 保存先と原本

通常は、入力と同じフォルダに`名前_patched.aep`を作成し、原本を残します。同名の出力がある場合は`名前_patched_1.aep`などの連番にします。**保存ダイアログは表示しません。**

元のファイル名で結果を保存したい場合は、`-p -overwrite`を指定します。

```powershell
.\delCppl.exe "D:\work\project.aep" -p -overwrite
```

この場合、原本を`名前_original_YYYYMMDD_HHMMSS_連番.aep`へリネームして保持し、処理結果を元の名前で保存します。日時は実行PCのローカル時刻です。`-overwrite`だけでは削除できません。

フォルダ・ワイルドカード検索では、上記の出力名・原本退避名に一致するファイルを除外します。再処理する場合はファイルを直接指定してください。同じパスを複数指定しても、処理は1回です。

CPPlがない・空の場合は変更せず、出力も作りません。処理できないファイルは理由を表示し、ほかのファイルは続行します。

### ショートカットへドラッグして使う

`delCppl.exe`のショートカットを作り、プロパティの「リンク先」を次のように設定します。

```text
"C:\tools\delCppl.exe" -p -wait
```

`C:\tools`は実際の配置先に置き換えてください。このショートカットへAEPやフォルダをドラッグすると、処理後にキー入力を待つため、結果を確認してから閉じられます。サブフォルダも処理する場合は、リンク先に`-sub`も追加します。

### オプション一覧

| オプション | 内容 |
|---|---|
| `-info` | CPPlの情報を表示。操作指定がない場合の既定動作 |
| `-patch` / `-p` / `-f` | CPPlの内容を削除して保存。3つとも同じ意味 |
| `-sub` | サブディレクトリも検索 |
| `-overwrite` | 原本をリネームして保持し、元の名前で保存。`-patch`などの指定が必要 |
| `-wait` | 終了時にキー入力を待つ。エラーやヘルプ表示時も有効 |
| `-help` / `--help` / `-h` | ヘルプを表示 |

`-info`と`-patch`は併用できます。`--`以降の引数はオプションではなくパスとして扱います。

### 中断と終了コード

**Ctrl+CまたはCtrl+Break**で中断できます。未完成の一時ファイルは削除し、確定済みの出力は保持します。原本を退避して保存・復元する短い区間は、中断を遅延します。Ctrl+Cなどによる中断後や標準入力のリダイレクト時は、`-wait`を指定していても待機しません。

| 終了コード | 内容 |
|---|---|
| `0` | 正常終了（変更不要を含む） |
| `1` | 対象なし、読込・保存失敗、非対応形式などの失敗あり |
| `2` | 引数不正 |
| `130` | 中断 |

## 両アプリ共通の注意点

CPPlの構造によっては、情報表示のみとなり削除できない場合があります。保存後のAEPは、使用するAfter Effectsで開いて内容を確認してください。

強制終了・電源断では、一時ファイルやリネーム済みの原本が残ることがあります。コンソール版の上書き保存で原本名へ復元できなかった場合は、表示された退避先に原本が残ります。
